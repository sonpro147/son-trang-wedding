# Khắc Sơn & Huyền Trang — thiệp cưới online

Thiệp cưới tĩnh chạy trên GitHub Pages. Trang chính chuyển hướng đến `online-invitation/site/`.

## Xem thiệp

<https://sonpro147.github.io/son-trang-wedding/>

## Sửa nội dung

- Chạy trình quản lý local theo hướng dẫn tại [online-invitation/docs/admin-setup.md](online-invitation/docs/admin-setup.md).
- Nội dung thiệp và sổ lời chúc nằm trong `online-invitation/site/data/default-content.json`.
- Ảnh và nhạc được lưu trong `online-invitation/site/assets/`.
- GitHub Pages chỉ phục vụ trang tĩnh. Lời chúc gửi qua Google Form cần được duyệt và thêm vào sổ trong trình quản lý trước khi cập nhật website.
